# LayoutEval на установленных раскладках (2026-10-06)

`swift run -c release TestRunner --layout-eval-real-tables` — тот же замер изолированных слов и
edge cases, но типизация и детекция идут по таблицам установленных US / RussianWin /
Ukrainian-PC (`KeyTableBuilder.installedTable` → `KeyboardTables.resolve`, как в приложении),
а не по статическим `.pc`. Отчётный режим; без этих раскладок печатает SKIP.

Mac, ANSI, macOS 27, ветка `claude/wave-3` (02e2a7b + апостроф):

- изолированные слова (en+ru, en+uk, en+ru+uk) — все строки **совпадают** с `.pc`-прогоном
  `--layout-eval-only`;
- edge cases — все группы совпадают (в т. ч. `fix en←uk apostrophe` 6/6, `keep en←en backslash` 6/6).

Вывод: на стандартных раскладках `.pc` — точная модель системных таблиц, цифры eval переносимы.
Расхождения стоит ждать на ISO/JIS-клавиатурах и нестандартных источниках (Phonetic, Colemak) —
прогонять там же этой командой.

Отличия от приложения: eval берёт ровно три источника (по одному на раскладку, установленные,
не обязательно включённые), приложение — все включённые, с откатом на `.pc` для источника без
таблицы и без Russian-Phonetic. Для стандартной тройки это одни и те же таблицы.
