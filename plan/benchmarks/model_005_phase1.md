# Фаза 1: триграммная модель — результаты (plan 005)

> **Дата**: 2026-09-29
> **Модели**: `Sources/LanguageModel/Resources/{en,ru,uk}.sfng`, n = 3, Witten–Bell,
> взвешивание `token`, штраф за неизвестный символ −12
> **Воспроизведение**:
> ```bash
> scripts/fetch-corpora.sh                      # корпуса + сверка с scripts/corpora.sha256
> swift run -c release ModelTrainer train       # → Sources/LanguageModel/Resources/*.sfng
> swift run -c release ModelTrainer eval        # таблицы ниже
> ```
> Обучение детерминировано: повторный запуск на тех же корпусах даёт побайтово тот же файл.

## Выбор взвешивания

Для каждого варианта — минимальный порог из сетки {0, 2, 4, 6, 8, 10}, при котором ложных
≤ 0.1% (для 2–3 букв ≤ 0.5%) во всех случаях «набрано правильно», и средняя полнота
исправлений при этом пороге.

| Взвешивание | ru 2–3 | ru 4–5 | ru 6+ | uk 2–3 | uk 4–5 | uk 6+ |
|---|---|---|---|---|---|---|
| **token** (выбрано) | T=6, 87.7% | T=8, 95.1% | T=8, 99.7% | T=6, 84.2% | T=6, 98.8% | T=6, 99.7% |
| token + balance | T=6, 86.7% | T=8, 94.8% | T=8, 99.7% | T=6, 85.2% | T=6, 98.7% | T=6, 99.7% |
| log | T=6, 70.0% | T=8, 90.3% | T=4, 99.9% | T=4, 78.3% | T=4, 98.0% | T=4, 99.8% |
| log + balance | T=6, 71.2% | T=8, 90.8% | T=4, 99.9% | T=4, 79.4% | T=4, 98.3% | T=4, 99.8% |
| type | T=4, 85.5% | T=10, 81.2% | T=2, 99.9% | T=4, 73.9% | T=4, 97.6% | T=2, 99.8% |

`token` лучше всего на коротких словах (2–5 букв), которых в тексте больше всего; на
длинных все варианты равны.

Модель — при пороге T = 6 (предварительно; точные пороги подбираются в Фазе 2).

Смешанные сообщения, английские вставки ≥ 4 букв в родной раскладке: **100%** (ru и uk)
при T = 6; ложных исправлений в смешанных сообщениях — 0 при T ≥ 4.

Цена — чуть больше ложных срабатываний на длинных английских словах при T = 6
(0.21% ≈ 3 слова из 1367); при T = 8 их 0.00% при полноте 99.1%. Короткие слова (1–3
буквы) модель в одиночку не решает — для них в Фазе 2 нужны `ShortWordTable` и контекст.
